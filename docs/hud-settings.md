# 导航框与班次提醒框设置

在主界面点击顶部 **HUD**。无需正在导航或已有提醒，页面也会提供两个预览框。

## 如何调整

1. 点击“导航框”或“班次提醒框”，也可直接点击对应预览框。金色边框表示当前正在调整的对象。
2. 拖动这个框改变位置；拖动时设置面板收起，松开后重新出现。
3. 鼠标停在框上滚轮调大小，也可使用加减按钮。界面显示所选框的保存比例，范围75%～200%。
4. 四角按钮只改变所选框；“恢复所选框默认值”只重置该框的位置和大小。导航框默认右上，提醒框默认顶部中央。
5. 提醒条显示可选自动收起或保持展开，与提醒管理页中的开关一致。
6. 点击完成或返回，设置保存在本机。

预览中的提醒框按完全展开尺寸显示，并标明预留空间；示例倒计时不是实际班次预测。实际提醒收起后仍保留方向、站台、时间来源和状态。

## 两个框如何避让

仅当两个框同时显示时启用互相避让。优先保留导航框位置，寻找提醒框附近可容纳的空位。如果导航框处于中间挡住两侧空位，可能将它移向较近屏幕边缘。

提醒框始终按完全展开的区域参与判断，因此收起与展开动画不会挤动导航框。窗口太小无法容纳时，临时缩小两个框；关闭自动适配也会保留这一保护。非常小的窗口可能因此降低文字可读性，需要放大窗口或降低保存比例。

自动避让、临时缩放不会写回用户保存的位置或比例；恢复窗口大小、关闭另一项提醒／导航后，按保存设置重新布局。设置页会同时显示两个预览，便于预先检查二者同时存在时的布局。

避让仅协调本模组的两个提示框，不检测其他模组的小地图、人物展示或游戏记分板；这些区域需要手动选择位置避开。

## 配置位置与迁移

配置位于当前游戏实例的 `config/mtrnav-client.properties`，不写入服务器存档。

- `hudScalePercent`、`hudPositionX`、`hudPositionY`：导航框大小和位置，保留原有键。
- `reminderScalePercent`、`reminderPositionX`、`reminderPositionY`：提醒框独立大小和位置。
- `hudAutoFit`：两框共用的自动适配开关，防重叠保护始终有效。
- `reminderKeepExpanded`：提醒保持展开开关，两处设置入口读取同一值。

位置为可用屏幕区域内0～1的比例。没有提醒框新字段的旧配置自动沿用原HUD大小设置作为提醒大小，位置使用顶部中央；下一次保存时补全字段。调整导航框大小后，不再连带修改提醒框大小。

## 换一个车站查询

起点、终点和到发车站输入框在首次点击或Tab进入时全选旧站名，直接打字即可替换，不必先点×；再次点击可以局部编辑。切到车站到发页时也会选中当前站名，输入后按回车或点击查询。选中文字本身不触发查询，也不清空活动导航。

## 验证范围

双HUD几何计算通过两个目标MTR核心的回归；真实客户端中的拖动、GUI缩放和视觉效果仍待实机复查，详见[验证记录](validation/verification.md)。
