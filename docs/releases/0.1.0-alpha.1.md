# MTR：站间物语 v0.1.0-alpha.1

首次公开 **Alpha测试版**。本版提供换乘规划、车站到发、列车提醒、双HUD设置和实验性的步行换乘／共享审核，欢迎报告复现步骤与日志。本版不作为稳定版推荐给需要成熟共享管理保证的正式运营环境。

## 下载与安装

- Minecraft **1.21.1**、Java **21**、MTR **4.1.0-beta.2**。
- NeoForge：`MTR-Navigation-neoforge-0.1.0-alpha.1.jar`。开发与协议测试使用21.1.249，实际用户客户端为21.1.251。
- Fabric：`MTR-Navigation-fabric-0.1.0-alpha.1.jar`，需要Fabric Loader 0.16.14及相应的Fabric API；开发测试API为0.116.17+1.21.1。
- 下载对应加载器的一个包放入实例 `mods`，更新前退出游戏并移走旧Navigation包。不要同时安装两个加载器的包。
- `SHA256SUMS.txt`提供附件校验值。MTR与Fabric API需要单独安装，未打入本模组。

## 主要功能

按 **N** 或 `/mtrnav` 打开。支持中英文站名、字母索引、附近起点、最多五种走法与最快／少换乘排序、线路分组到发、默认提前九分钟的单班次提醒，以及独立可调的导航／提醒HUD。提醒收起保留方向与站台，两个HUD自动避让。

个人步行连接通过游戏内表单录入，时间计入赶车计算，到达由玩家确认。JSON导入先预览，不自动公开。支持新版Navigation服务端时，玩家可提交共享建议，OP等级2及以上管理员审核通过后才发布。个人规则用于服务端查询前征得同意，不进入共享库。

## 客户端与服务端

客户端必须安装；服务端可选。只有MTR的服务器需要原生地图时刻服务可用，Overlay目录不能代替班次数据。新版共享审核需要服务端安装本模组；不通过Overlay上传。旧Navigation v1服务端保留最多三个纯乘车方案，不发送不支持的新功能消息。

## Alpha已知限制

- 原生兼容时刻服务可能暂时无响应，需手动重试；五秒未更新的数据标记过期。原生模式不可靠关联实际车辆，行程进度需手动确认。
- 只支持本维度铁路客运；默认未来六小时、最多四次换乘。没有全天时刻表、未来指定出发、道路寻路或实际地图轨道高亮。
- 步行规则属于人工估算，不检查入口、楼层、墙体和道路，不自动连接附近车站；班次提醒与行程相互独立。
- **共享审核与步行导航为实验性功能**。双完整Minecraft客户端审核联合验收尚未完成，不能将协议测试等同完整游戏验证。
- **Fabric完整游戏内流程仍待验收**；其构建、目标MTR核心和隔离专服协议测试已通过。
- GUI缩放和长时间连接／内存稳定性仍需继续实测；本版不声称此前用户遇到的掉线、内存增长或黑闪根因均已解决。

## 已执行验证

NeoForge目标Core 97项：96通过、1跳过、0失败；Fabric目标Core 97项：95通过、2跳过、0失败。两个隔离专服均完成三个协议连接的提交、权限拒绝、审核发布、第二连接同步、个人规则隔离、取消释放及旧v1查询验证。NeoForge联机界面已补录实机截图。

完整记录和使用方法见[README](https://github.com/teamCreating/MTR-Navigation/blob/v0.1.0-alpha.1/README.md)、[验证记录](https://github.com/teamCreating/MTR-Navigation/blob/v0.1.0-alpha.1/docs/validation/verification.md)、[步行管理](https://github.com/teamCreating/MTR-Navigation/blob/v0.1.0-alpha.1/docs/walking-transfers.md)及[HUD说明](https://github.com/teamCreating/MTR-Navigation/blob/v0.1.0-alpha.1/docs/hud-settings.md)。当前地图对接维持JourneySelection v1，只导出乘车区间。
