# MTR：站间物语 0.1.1

本版统一为 Ore UI，并加入车型选择与手机导航式行程摘要。README 使用「苔灯群岛」架空测试存档的全新游戏截图；所有演示线路、地点与班次均为测试数据。

## 更新内容

- 全页面统一 Ore UI：按钮按压与回弹、带 I/O 标记的开关、双行顶栏，以及文字与控件对齐；字体跟随 Minecraft。
- 车型查询：读取 MTR 线路类别、逐节车厢车型、车厢数及实际／计划编组；最多多选 16 个车型，支持优先或必须乘坐，搜索与剪枝同时检查车型。
- 行程摘要：线路色块、MTR 自带交通图标与步行分钟按行程顺序排列；编组顺序与车型 ID 可展开查看。
- 查询与选站：最多五种走法、独立列表与详情滚动、途经站直接展开、中英文目录搜索与排序。
- HUD 与步行管理：双 HUD 分别拖动、缩放和自动避让；步行连接表单与共享／个人管理分组更清楚。
- 多版本：Minecraft 1.21.1／1.21.4 各提供 NeoForge 和 Fabric 安装包。

## 安装

需要 Java 21、Minecraft 对应版本的 MTR 4.1.0-beta.2。Fabric 还需要对应版本的 Fabric API。根据文件名选择 Minecraft 版本和加载器，退出游戏后替换旧 Navigation JAR，每个实例只保留一个对应的安装包。

客户端可连接仅安装 MTR 的服务器使用原生兼容查询；车型条件需要服务端支持新版 Navigation 查询通道。既有 v1／v2 协议、地图选择接口和 HUD 偏好保持兼容。
