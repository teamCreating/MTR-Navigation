# MTR：站间物语 0.1.2

本版彻底告别旧版 Ore UI，全面升级为零外部依赖的自研现代「轨道导视 × 候车厅 PIDS」一体化工作台、手机导航风格 2D 实景线网地图与半透明新一代双 HUD，同时清理冗余内置字体与历史预览代码，安装包大幅瘦身。

## 更新内容

- **一体化工作台与 MC 深板岩外框**：左侧常驻导航轨统一承载「换乘查询 / 车站到发 / 当前导航 / 步行换乘 / HUD 设置」，外框呼应官方模组图标采用像素切角深板岩边框，内部控件保持纯粹干净的现代暗色风格；选站、车型条件、班次提醒与步行编辑均改为右侧滑出抽屉。
- **快捷键与视图记忆**：未在输入框打字时，再按一次打开键（默认 `N`，自动跟随自定义键位）即可一键收起界面；关闭再打开自动记住「步骤时间轴 / 2D 线网拓扑」选择。
- **手机导航级 2D 实景线网地图**：
  - 真实存档下自动采样当前已加载区块地表方块与高度山影，叠加平滑弯道轨道、动态流动方向箭头、水滴形 `起`/`终` 图钉、带步行时长的换乘气泡、玩家实时 GPS 蓝点与朝向光锥、红针指北针和动态米制比例尺；
  - 支持常规方案与「线路参考」自动聚焦、大跨度线网抗离群点默认取景、`◎` 一键切换「聚焦路线 / 全网总览」、深度缩放与缩放自适应标签避让。
- **候车厅 PIDS 电子大屏**：实时时钟、线路筛选胶囊、大号倒计时、图形化车厢编组条与一键滑出到站提醒。
- **半透明双新 HUD 与交互式设置**：列车门动态 LCD 线路进度条与顶部提醒胶囊采用半透明暗色玻璃质感；HUD 设置页内置 16:9 实时可拖拽屏显预览 + 1:1 近景样式预览，并支持一键进入全屏实景拖拽。
- **体积大幅瘦身与全兼容**：清除旧版 16 个 Ore UI 页面、废弃实验预览与未启用的 8 MB+ TTF 字体资产，并移除多余的 `FontAccessor` Mixin；完全保留 `NavigationApi`（`JourneySelection` v1）、服务端 v1/v2/v3 协议与 `config/mtrnav-client.properties` 配置兼容。

## 安装

需要 **Java 21** 与对应版本的 **MTR 4.1.0-beta.2**（Fabric 另需对应版本 Fabric API），无需任何额外 UI 模组。根据文件名选择 Minecraft 版本（`1.21.1` / `1.21.4`）与加载器（`neoforge` / `fabric`），退出游戏后替换旧版 JAR 即可。

## 验证

四个目标安装包（`1.21.1` / `1.21.4` × `NeoForge` / `Fabric`）均已完成全量单元测试（`test` + `testFabricCore`，含新增纯 Java UI 引擎与大地图离群点聚焦单测）、`tools/verify_build.py` 字节码与元数据校验，以及 Minecraft 1.21.1 实机与黑山 7.5 真实 MTR 存档验收。附件 `SHA256SUMS.txt` 与 `manifest.json` 可用于核对完整性。
