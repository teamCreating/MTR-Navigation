# MTR：站间物语 0.1.3

本版针对 100+ 站大型多人 MTR 服务器的实机反馈进行重点优化与修复，大幅提升 2D 线网地图流畅度与可读性，升级无实时班次时的多条「线路参考」对比能力，并修复选站抽屉滚动跳回顶部的问题。

## 更新内容

- **大型多人服（100+ 站）2D 线网图性能与防重叠优化**：
  - 底图生成彻底移除逐像素遍历全网车站的 $O(\text{像素}\times\text{站点数})$ 循环，改为纯 $O(1)$ 每像素渲染，并加入区块查询缓存与拖拽/缩放 100 ms 节流。
  - 修复未查询路线时 174 站全部强制走高优先级线段避让导致的严重掉帧与标签堆砌，以及放大后屏外站名被吸附挤压在地图上下边缘的问题：全面启用严格视口裁剪、非必显站名零重叠避让与展示上限控制，并对高密度背景走廊按站对去重。
  - 超过 24 站的大服首次打开自动聚焦起点周围邻域（约 12 站），并修正南北超长跨度路线的上下安全边距，避免起终点贴边遮挡。
- **「线路参考」升级为多方案对比（最多 5 条）**：
  - 在无实时发车班次或原生兼容兜底模式下，自动搜索并按线路组合去重给出最多 5 条不同换乘走廊的参考方案（保留环线双向走法），并跟随顶部「最快到达（路径最短）/ 少换乘」排序动态重排。
  - 左侧参考卡片展示里程、换乘次数、总站数、首推徽章及彩色线路链；鼠标点击或键盘 `↑/↓` 切换时，右侧 2D 线网图自动重新聚焦到对应走廊，步骤时间轴同步更新。
- **修复「车站到发」选站抽屉每秒弹回顶部**：
  - 原生兼容模式每秒轮询到发数据时仅在确实新增站台时才更新 `Catalog` 对象；选站抽屉后台目录刷新时保留用户当前滚动位置。

## 安装

需要 **Java 21** 与对应版本的 **MTR 4.1.0-beta.2**（Fabric 另需对应版本 Fabric API），无需任何额外 UI 模组。根据文件名选择 Minecraft 版本（`1.21.1` / `1.21.4`）与加载器（`neoforge` / `fabric`），退出游戏后替换旧版 JAR 即可。

## 验证

四个目标安装包（`1.21.1` / `1.21.4` × `NeoForge` / `Fabric`）均已完成全量单元测试（`test` + `testFabricCore`，含 174 站大网邻域聚焦、超长南北路线安全边距与多走廊线路参考去重排序单测）、`tools/verify_build.py` 校验，以及 174 站真实多人服务器实机验证。附件 `SHA256SUMS.txt` 与 `manifest.json` 可用于核对完整性。
