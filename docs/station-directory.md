# 车站目录与快速查阅

主界面的“全部车站”打开独立目录页；定位有多个候选时使用相同样式的附近车站页。列表保留每个原生车站ID，同名站不会合并，可用坐标区分。

## 选中与悬停

鼠标悬停用蓝灰色底和细边框；真正选中用亮黄铜底、金色双边框、左侧箭头及更亮的文字。页脚同时写明已选车站。选中后使用底部按钮设为起点、终点或查看到发；双击或回车使用默认用途。步行管理、车站／站台选择等通用列表也使用相同选中样式。

## 排序和字母索引

右上排序按钮依次切换A–Z、Z–A、离我最近。每次打开普通目录默认A–Z，附近车站默认距离排序；本轮不新增永久排序偏好配置。

宽窗口显示一排字母，点击跳转并选中该组第一站；窄窗口使用“索引”按钮打开分组列表，再选所需字母。只显示／启用当前搜索结果中存在的分组，索引不会清空搜索。距离排序下点击字母，会切换到A–Z后跳转。

- 中英分段名称优先使用英文分段归组，忽略大小写及常见拉丁音标。例如“戴安澜 | Dai'anlan”在D。
- 纯中文名称按常用汉字首字的拼音字母归组，组内使用Java中文排序；多音字采用单字顺序，不能保证所有地名读音正确。
- 数字开头归“#”；生僻字、其他文字或符号等无法归组的放在“其他”（索引显示“…”），不会从目录移除。
- 同名同键的条目最后按原生ID稳定排序。数字组在前、其他组在后；Z–A反转字母及组内名称顺序。

搜索框仍支持原有中英文包含搜索；字母索引不等于完整拼音输入法或拼音搜索。

## 距离

离我最近使用选用该模式时的位置快照，显示到车站坐标的水平直线距离。点击“重新定位”重新采样，避免玩家移动时整个列表不断跳动。未知坐标的站在普通目录仍可搜索选择，距离排序放在已知站点后；附近站定位页仍只列已知坐标候选。

距离不代表入口位置、道路长度或可步行连通，也不自动创建步行换乘连接。

## 键盘

点击列表行退出搜索框焦点后，可直接按A～Z跳到对应组。上下键选择车站，回车使用默认用途；Page Up／Page Down翻页，Home／End浏览首尾。搜索框获得焦点时，字母键用于正常输入，不会抢作跳转。

## 验证

自动回归覆盖双语／纯中文及拉丁音标归组、数字和未知字、升降序、同名不同ID稳定顺序、距离未知及并列、过滤后的索引、无结果。选中高亮、窄窗口索引及中文输入的真实视觉仍待用户实机复查，详见[验证记录](validation/verification.md)。
