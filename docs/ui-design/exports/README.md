# 预览图片

`pencil`：从项目Pencil画布导出的版式稿。优先看有意义的文件名：`main-navigation.png`、`components.png`、`long-stations.png`、`no-results.png`、`no-timetable.png`、`hud-editor.png`、`compact-navigation.png`。图层ID命名的文件是同一导出的原始文件。

`game`：真实游戏F2截图，没有用设计图替换画面。文件名包含场景、中文字体及窗口尺寸；相邻JSON保留原始截图路径。`1.21.4-fabric`是最终主要预览；`1.21.1-neoforge`使用用户当前Modern UI配置的隔离环境。

比较字体时请看同一目录的`journeys-pixel-1920x1080.png`与`journeys-smooth-1920x1080.png`。Modern UI目录对应文件名包含`modernui`。

`connection-test`仅用于最初验证Pencil能修改、导出组件，不是最终视觉方案。当前全部为测试数据；视觉与字体尚待用户选择。
