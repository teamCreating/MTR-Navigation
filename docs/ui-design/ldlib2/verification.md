# 三种风格试点验证

日期：2026-11-12。此记录对应用户要求“都试试做出来看看怎么样”，用于选择视觉方向。正式导航、HUD及其他页面尚未迁入LDLib2。

## 实际完成

- MC1.21.1 NeoForge隔离客户端打开三种风格，默认同一Noto中文候选、MC英文数字、同一测试内容及520×360 GUI布局；有效缩放2×。
- 1920×1080三套截图均显示完整五条双行方案，正文与页脚按钮在框体内；854×480改用列表／详情切换和滚动，导航操作保持可见。Create版最后按SpriteTexture的左／上／右／下边距顺序修正侧框，补拍小窗口。
- 三种风格分别打开真实LDLib2可视化编辑器，保存对应`.ui.nbt`，返回加载保存稿并重新绑定交互。XML编辑器可打开对应XML；XML和NBT不双向同步。
- 检查场景包括五方案、长中英文站名、无结果、无可乘班次。无班次时导航禁用。中文字符通过定向窗口字符消息输入后，字段及详情同步显示，光标可见。
- 在隔离MTR＋Modern UI 3.13.0.1与复制的用户字体配置组合中运行。三套对照截图来自此组合；没有修改Axolotl实例。
- 正常四目标全部构建通过。四个正常安装包中均无LDLib2试验类或`ui/ldlib2`资源。试验单独打包，最终XML和三套模板已入包。
- 试验目标执行既有`test`及`testFabricCore`：各101项，99通过、2项既有跳过、0失败、0错误。最终仅资源更新后重打试验包，没有无理由重复回归。

## 使用与边界

F5切换风格，F6切换中文字体，F7切换场景，F8重载，F9可视化编辑，F10 XML编辑。顶部“编辑界面”也可打开可视化模板。查询／导航使用明确标注的测试数据。

“原版控件”版使用当前Minecraft按钮／输入框／页签贴图，运行框架仍为LDLib2；它不是原版Screen/Button实现。Create版为本地参考，保留上游来源和许可记录，未作为可公开发布素材验收。

本轮没有完成操作系统输入法候选窗、全部快捷键／选区的人工验收，也没有完成LDLib2在另外三个构建目标的移植。1280×720、2560×1440及HUD缩放的既有原生预览验证不能替代本试点验收。视觉、字体选择以及正式页面接入仍等用户看对照后决定。

已知日志中存在上游资源与可选模组提示，未将整个客户端日志描述为无错误。截图由窗口精确标题定向操作取得；截图尺寸检查、人工画面检查及构建检查分别记录，不以构建成功代替视觉通过。
