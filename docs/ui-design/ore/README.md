# 全页面 Ore UI 版本

用户确认范围：正式查询、车站目录、到发、当前行程、更多菜单、提醒设置、HUD 编辑、步行设置、步行编辑、个人/共享/审核管理及附属选择/文字页。正式入口直接复用既有真实服务；字体跟随 Minecraft 当前字体。查询与服务端协议未更换。

组件说明见 [组件规范](components.md)。

## 已实现

- 居中标题和返回/更多/关闭入口，下方独立的三项导航。宽屏保留方案/详情双栏，854×480 收起条件后显示三条双行方案。
- Ore 主/次按钮分别具有绿色/中性底座、内侧亮边、暗面、按下位移和回弹；鼠标松开且仍在按钮内才执行。移出释放取消；键盘支持按下/松开及重复按键抑制。
- 原生输入框、灰白焦点、独立页签、分段选择、带 I/O 标记及正方形滑块的开关和可拖动/键盘调整的 HUD 缩放滑块。所有正式页面使用共用控件。
- HUD 编辑将显示、位置、提示分开；提醒展开开关仅在编辑提醒时出现。拖动时隐藏设置，沿用实际双 HUD 避让与独立偏好；可切换到完整预览，避免窄窗口面板遮挡。
- 线路轴统一两单位宽，仅连接首末站中心；空心站点与文本基线对齐。“途经 N 站”直接点击展开/收起，每段线路独立，也可用键盘聚焦操作。
- 保留已有 HUD、提醒和步行偏好；旧 uiSkin 键仍能读取，正式外观固定使用本轮 Ore 方向。

## 参考与适配

只读核对本机基岩版 `Microsoft.MinecraftUWP_1.26.6301.0_x64` 的 Ore 菜单主题、抬升按钮 default/hovered/focused/pressed 状态、页签和控件结构。其抬升按钮默认负上边距、按下时归零，配合独立底座；此前直接沿用 Java 按下即跳页的行为无法呈现该状态，现已改为松开触发。

按钮按压/回弹的 60/100 ms 是本项目原生适配参数，不声称是上游精确时长。开关进一步核对了实际 BaseSwitch：轨道 6×2.8 rem、滑块 3.2×3.2 rem、0.4 rem 底边，250 ms step-start 动画在四分之一进度发生拉伸、位移和回返；实现按半尺寸 GUI 单位绘制同样的状态结构。

图形由代码原创绘制，未分发基岩版贴图、字体或 JavaScript。公开页面参考：[Creating “Create New World”](https://www.minecraft.net/en-us/article/creating-create-new-world)。

## 隔离验证入口

`dev.ps1 -Platform neoforge -MinecraftVersion 1.21.1 -GradleArgs @('runClient','-PoreReview','-Pquickplay=NavTest','--offline')` 启动项目独立实例，接测试世界里的实际 MTR 数据。加 `-PoreFixtures` 才使用明确标注的静态测试数据。

测试数据入口用于五方案、长名称、空白、无班次、到发、HUD、当前导航、加载、失败和无结果检查；F7 切场景，F6 开 HUD。普通安装包不会启用审计或自动打开窗口。`ore_review.py`、`record_ore_press.py` 只操作精确项目窗口。

游戏截图位于 `../exports/game/*-ore*/`。验证过程中保留的旧截图只代表相应时点；最终通过项目和限制以 `verification.json` 为准。实际游戏反馈继续迭代，不把编译成功当作用户视觉确认。

## 对齐修正

标题图标为16单位，正文起点统一留8单位间隔；表单标签与输入框分开，文本及清除图标使用同一视觉基线。查询/交换按钮对齐输入区域，底部常规动作使用20单位高度。步行耗时和使用方式分组统一底边，宽窗口留8单位横向间距。

后续自动游戏检查使用显式 `-PoreBackground`：在游戏线程分发原生 Screen/控件事件，使用 Minecraft 原生截图函数读取实际帧缓冲，不移动桌面鼠标或反复获取系统焦点。较早的按钮按压实测也通过过定向窗口消息；两种记录在对应 JSON 中分别注明，输入法组合态仍需人工检查。

2026-11-14：子页面顶栏使用 16 GUI 单位的开放式线路节点标志，取消实心绿色底框；图形中心与标题文字对齐。0.1.1 README 截图改用「苔灯群岛」架空场景，拍摄记录见 `docs/screenshots/0.1.1/capture.json`。
