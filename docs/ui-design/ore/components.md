# Ore UI 组件规范

## 框体与标题

正式页面用 #48494A 主体、#313233 凹陷区域、#1E1E1F 边线和 #E6E8EB 标题栏。标题栏28 GUI单位；窄查询页24单位。标题图标16单位，图标到文字8单位；文字与图标视觉中心对齐。主界面使用居中标题及独立的三项导航行。页面间保持同一字体和样式入口。

## 按钮与焦点

常规操作20单位，图标18单位；查询按钮跟随实际输入区域高度。绿色用于主要动作，中性灰用于次级动作。按钮面包含独立底座和四侧内缘，鼠标按住时下沉3单位，松开后回弹；在外部松开取消。键盘按下与松开对应同一逻辑，按键自动重复不重复执行。悬停和键盘焦点分别处理，焦点使用明显边缘。

按钮与绘制共享原生控件矩形，滚动内容绘制/点击受相同视口约束。禁用状态不接受操作。列表仍使用文字而非物品槽，双行名称/说明分别留出空间，截断的输入值保留完整可编辑内容。

## 输入与选择

输入框使用 Minecraft 原生编辑、选区和旁白行为。双行输入由上方标签和下方凹陷输入组成，清除图标对齐输入文字；交换和查询按钮对齐实际输入区域。英文、数字、中文均跟随玩家当前 Minecraft 字体，不替换全局字体。

页签使用下划线；互斥选项采用分段选择；二值设置采用开关。功能不可用的按钮明确禁用，原因显示在页面或提示中。

## 开关

轨道按上游6×2.8 rem比例缩为30×14 GUI单位，滑块16×16，包含独立下沿和亮边。左侧绿色I、右侧中性O均在滑块下保留，状态不只依靠颜色。禁用时整体变暗。

切换250 ms，step-start四阶段：位移0→3→14→13→14，滑块宽度16→20→16→16→16；关闭方向镜像。该结构来自本机只读 Ore BaseSwitch 样式，图形由代码绘制。

## HUD 与路线详情

设置页将显示、位置及说明分开。导航/提醒分别选择并独立保存大小和位置；自动适配沿用双 HUD 布局。拖动时隐藏设置；“预览”可完全隐藏面板，特别用于窄窗口。

线路轴为两单位宽，仅在实际首末节点间连接。端点与途经节点的中心对齐对应站名行；途经站使用可聚焦的原生展开控件，每段独立保存展开状态。步行段、站台与时间保留不同层次。

## 限制

本轮目标是键鼠；没有新增触摸或手柄支持。按钮60/100 ms按压/回弹为本项目适配，开关250 ms分段序列已按源样式核对。所有可分发图形均为本项目绘制，不带基岩版上游贴图、字体或脚本。
