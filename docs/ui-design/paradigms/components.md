# 原生对照组件规范

## 尺度与布局

- 所有数值为 Minecraft GUI 单位，按 2 单位网格组织，间距 4 / 8，图标按钮 18×18，标准控件高 20，文字基线间隔 12。
- 四套方向共用最大 660×416 框体、固定页首/页脚；有效 2× 下 1920×1080 显示至少五条双行结果。
- 框体宽不足 540 或高不足 330 时使用窄布局，隐藏侧栏，列表/详情切换；854×480 收起条件后至少三条双行结果。
- 查询条件独立收起，主要操作固定在页脚；选站与 HUD 返回查询时保留输入、选中项与滚动位置。
- 绘制、原生控件、滚动条和鼠标命中统一使用 `UiComparisonLayout` 的矩形；内容不得覆盖页脚。

## 控件与状态

- 按钮与列表行使用原生 `Button`，输入使用原生 `EditBox`；保留 Tab、Enter、文本选区、剪贴板和旁白通道。
- 普通、主要、选中、悬停/焦点、禁用分别呈现。选中项有边框或边缘标记，并在旁白名称中标记已选中；状态不只依靠颜色。
- Java / 融合按钮与页签从运行时 `minecraft:widget/button*`、`minecraft:widget/tab*` 取材，页签与按钮分开；BE 主/次按钮分别使用绿色/中性色底座；AE2 使用官方参考的冷灰紫凹凸框。
- BE 使用独立的扁平侧栏、页签、分段选择、开关与原生滑块。开关点击/键盘激活，滑块拖动或键盘调节；不把每一种设置都画成普通按钮。Java 方向沿用白色列表选框，融合方案保留自己的选中标记。
- 辅助图标为统一整数像素绘制，全部带可读名称和提示；被截断的列表内容提供完整名称提示，详情按同一字体实际宽度换行。
- 查询无结果、加载、失败分别有标题和下一步说明；线路参考不能启动导航。失败可通过查询重试。

## 字体

对照仅在本预览中切换中文候选，测量、裁切、换行、绘制、输入与光标共用同一字体服务。风格切换保留当前字体，字体切换保留输入与滚动偏移。正式页面的跟随 MC 字体设置不变。

对照来源与首稿修正见 `source-review.md`。实际来源包括 AE2 官方 1.21.1 资源、Java 官方客户端资源，以及只读核对的本机基岩版 Ore UI 资源。

## HUD

导航框和班次提醒框各自保存大小、位置；支持 100% / 150% / 200%、自动适配、四角定位、重置、滚轮和拖动。Shift + 方向键提供定位替代操作。双框复用已有 `HudArrangement` 避让，预览画布裁切边界与拖动命中一致。

拖动时隐藏设置控件，释放后恢复；小窗口设置可滚动。保存/恢复只操作本次会话快照，关闭后不写入正式偏好文件。
