# 界面交互演示

本目录是选择 A／B／C 布局时使用的浏览器交互原型，采用示例数据；已选择 A 布局。原生模组后续增加的黄铜包角、HUD 拖动避让、可滚动站名候选和线路参考以实际源码与主 README 为准；原型截图和旧 HUD 大小示意不代表当前版本。

在浏览器中打开 `index.html`；当前会话亦通过 `http://127.0.0.1:8765/` 提供本机演示。

- A：铁路行程册，左右分栏和线路时间轴。
- B：车站时刻板，用表格比较方案。
- C：简洁分步，浅色布局和较少的按钮。
- 点击方案、开始行程、模拟上车和下车；按 N 展开／收起行程。
- 可切换两行／三行 HUD，显示旧 HUD 范围进行比较；可记录当前选择。

使用排版示例数据，不连接服务器。背景来自用户提供的游戏录像，非模组分发资源。预览中的网页字形和抗锯齿不代表 Minecraft 的最终字体效果。

浏览器交互检查覆盖风格切换、方案选择、上下车阶段、返回上一步、N 键、两行 HUD、旧范围比较、结束行程、交换站点、独立车站到发搜索及返回查询，共 15 项通过；记录在项目 `build/validation/ui-preview-checks.json`。

用户已选择 A“铁路行程册”。原生模组已实现 A 布局，并补上独立车站到发页和点击站名查看到发的入口。B、C 保留为历史候选演示。
