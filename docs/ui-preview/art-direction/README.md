# Create 原版 GUI 本地试做

使用用户给出的 Create 原版贴图：`stock_keeper.png` 用于卷边、木框与纸质输入框，`widgets.png` 用于 18×18 控件状态和选中边框，`schedule.png` 用于正文的深色底板。

主界面最大宽度为 460 GUI 单位，使用紧凑双栏与两行方案。高分辨率窗口适当增加像素显示比例，五种方案返回后重新计算窗口高度。普通灰按钮使用深色文字，绿色按钮及深色正文使用浅色文字；选中项不再使用淡紫色底板。输入框保持无阴影文字。

素材版权归属与上游许可保留在资源目录中。此为本地试做，未发布，不主张第三方资产的再分发许可。

回退点：`build/ui-backups/before-create-source.zip`。先前未采用的生成稿仍保留在本地备份中。
