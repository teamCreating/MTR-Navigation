- 可选 Overlay 兼容测试使用 GitHub v1.5.2 的 NeoForge 1.21.1 正式附件，并核对发布的 SHA256SUMS。

## 自动验证

当前两个目标 MTR Core 的回归均通过：NeoForge 34 项通过、1 项跳过；Fabric Core 33 项通过、2 项跳过。覆盖直达、换乘余量、单向线路、重复停站、同名站、显式连接、贯通、排序、范围限制、时钟过期、车辆身份、地图区间、分块组装、原生请求生命周期，以及 HUD 缩放／位置和无班次线路参考。

到发适配测试直接调用两个目标包的 `Siding.iterateArrivals`，未用模拟接口替代其签名；原生地图兼容测试使用实际 `StationAndRoutes`／`Departures` DTO 的正式 JSON 序列化。另有一项读取真实 Overlay 发布包的全网快照测试。

显式测试世界生成器默认跳过；仅 `-PgenerateFixture` 时向指定的新目录生成 MTR 运营网络，拒绝覆盖已有目标。

以上是早期版本验证过的能力，不作为本轮黄铜界面与 HUD 编辑器的视觉验收。

### 布局与连接稳定性修订

查询界面改为原生平面按钮、按需展开站点候选、可直接点选的方案卡片和线路颜色时间轴；小窗口查到结果后自动收起搜索区。当前导航独立显示阶段相关操作，HUD 在右上角显示下一操作、站台、倒计时和实际绑定的打开按键。

旧兼容版在成功返回方案后仍出现连接超时，用户提供的日志有三次超时记录，用户确认仅该客户端受影响。日志没有直接指向 Navigation 的崩溃堆栈，不能将时刻服务无响应直接当作掉线根因。

针对确认存在的性能及请求生命周期问题：时刻与目录解析移至后台；原生请求同一时间最多一个；全网时刻每三秒取一次，与 MTR 原生三秒缓存匹配；失败后停止自动轮询，至少十五秒后由用户显式重试；没有打开导航或活动行程时不请求；移除导航触发 Overlay 全量同步的逻辑。新查询取消旧任务，搜索有五秒时间、两百万操作和一万待处理标签的限制。出现超过五秒的客户端 tick 间隔时写诊断日志。

## 实际限制

兼容路径依赖 MTR 原生系统地图服务可用；地图时刻数据不暴露车辆实例及完整班次身份，故不自动确认乘车进度，也不将其路线估算标成实时预测。

当前实测不是大型真实网络的性能成绩；不宣称预知信号拥堵、临时人工驾驶或未来取消。没有进行地图区间高亮或更改 Overlay 的现有渲染。

Fabric 安装包构建及目标 MTR Core 回归通过。Fabric 游戏启动停留在资源加载阶段，尚未完成其世界内界面验证；未完成两个加载器的独立专服完整实测。

## 2026-10-25：HUD 编辑、远途查询及外观修订

用户自行启动客户端检查，提供了重复 HUD 入口、底部编辑面板遮挡以及真实网络触及搜索上限的截图。16:27～16:28 的客户端日志明确记录约 45,660 条事件的查询触及资源上限；这是搜索没有完成，不能据此判断站名错误或线路停运。

本轮源码包含以下修订：

- 仅保留全局顶部 HUD 设置入口。三行 HUD 默认 150%，大窗口约 405×97 实际像素，可在 75%～200% 调节，默认自动限制小窗口占用。位置按可用区域比例保存。
- 拖动 HUD 时隐藏设置面板，HUD 移到底部后面板转移到顶部，底部区域也可放置。四角预设、恢复默认及当前行程预览保留。
- 原版石质按钮配黄铜包角、铆钉和轨道刻度，使用用户指定的图标及中文名“MTR：站间物语”；无机械动力运行依赖。
- 站名候选不再截断为前三项；可在候选框内滚动全部匹配，滚动条与提示显示位置。滚轮优先处理候选列表，再处理行程内容。
- 搜索使用反向可达性、最短运行时间和最低换乘次数估计指导扩展，结合换乘余量，减少无关中间站和后续班次的扩展。保留原有时间、操作数、队列和取消限制；存在贯通班次时对换乘下界采用保守策略。
- 无可乘方案时显示有向拓扑线路参考，保留原生站台和重复停靠序号；区分无班次、超过换乘上限和计算未完成，不编造时刻、不标为已确认停运，也不允许开始班次导航或向地图接口发布参考路线。
- 新增 [Overlay 对接指南](../overlay-integration.md)，说明 API、事件、身份规范、精确区间及联调边界。

大网络回归使用 46,200 条事件、两条高频线路和一次换乘，要求“最快到达”“少换乘”均返回到达远端站的两段方案；两种排序合计执行约 1.1 秒（本机一次测量，不是实际服务器性能保证）。新增线路参考测试覆盖无班次、八次换乘远途、单向、同名、未连接邻站、显式连接和重复停靠。

两个加载器均构建通过，测试数量见上文。新的 HUD 拖动避让、候选框滚动和黄铜外观已完成编译核验，尚待用户在实际游戏中复查；本轮不接管或重启用户客户端。Fabric 世界内和两个加载器独立专服的完整实测仍未完成。
